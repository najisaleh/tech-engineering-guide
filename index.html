الفصل الأول: هندسة عتاد الحاسوب والصيانة الإلكترونية

مرجع الفحص الميداني للوحات الأم، دوائر التغذية (ATX Power Supply)، وصيانة الشاشات والمركبات السطحية (SMD).

1. قيم الفولتيات القياسية في مزود الطاقة (ATX Power Supply)

لون السلكالجهد القياسيالسماحيةالوظيفة الأساسية في اللوحة
الأصفر (Yellow)+12V DC±5% (11.4V - 12.6V)تغذية المعالج (VRM)، البطاقات الرسومية، والمحركات
الأحمر (Red)+5V DC±5% (4.75V - 5.25V)تغذية منافذ USB، دوائر المنطق، والأقراص
البرتقالي (Orange)+3.3V DC±5% (3.14V - 3.47V)تغذية الرامات، شريحة BIOS، وبطاقات PCIe
البنفسجي (Purple)+5V VSBجهد الاستعدادتغذية دائرة Super I/O قبل الضغط على زر التشغيل
الأخضر (PS_ON#)5V ينخفض إلى 0Vإشارة تشغيلعند توصيله بالسلك الأسود (GND) يعمل مزود الطاقة
الرمادي (PWR_OK)+5V DCPower Goodإشارة استقرار الفولتيات للوحة الأم لبدء الإقلاع

2. تتبع أعطال اللوحة الأم وصيانة إضاءة الشاشات (LED Backlight)

  • فحص دائرة تنظيم الجهد (VRM): افحص عدم وجود قصر (Short) بين خط 12V والأرضي قبل تركيب المعالج، وافحص ترانزستورات MOSFET (Gate, Drain, Source).
  • شحن شريحة BIOS: عند توقف اللوحة عن عرض البيانات (No Data) مع سلامة الفولتيات، فك شريحة الـ SPI Flash وأعد برمجتها عبر المبرمجة.
  • صيانة إضاءة الشاشات (LED Backlight): بعد استبدال مساطر الـ LED بالكامل، يُنصح بتخفيض تيار الـ Driver بنسبة 20% عبر زيادة قيمة مقاومة الإحساس بالتيار (Current Sense Resistor) بجوار آيسي الـ Inverter لمنع احتراق الليدات مستقبلاً.

الفصل الخامس: البرمجة والأتمتة بلغة Python

سكربتات جاهزة للمهندس التقني لفحص الشبكة وقراءة المنافذ التسلسلية (Serial/RS485).

1. سكربت فحص السيرفرات وقراءة منفذ Serial للوحات الصناعية

import serial, time

# قراءة بيانات لوحات التحكم عبر منفذ RS-485 / COM
ser = serial.Serial(port='COM3', baudrate=9600, timeout=1)
print("بدء الاستماع للوحة التحكم...")
try:
    while True:
        if ser.in_waiting > 0:
            line = ser.readline().decode('utf-8', errors='ignore').strip()
            print(f"[بيانات مستلمة]: {line}")
        time.sleep(0.1)
except KeyboardInterrupt:
    ser.close()

الفصل السادس: الأنظمة المدمجة والتحكم الصناعي (مرجع المصاعد الشامل)

دليل هندسي متكامل لبرمجيات وأعطال لوحات التحكم للمصاعد: Monarch (Nice3000) و ARCODE (ARKEL).

1. لوحات Monarch (Nice3000 / Nice3000+): البارامترات والأعطال

الرمز / البارامترالاسم الفنيالشرح والإجراء الهندسي
F0-00Control Mode0: محرك غير تزامني (Geared)، 1: محرك تزامني (Gearless PM).
F1-01 ~ F1-05Motor Nameplateإدخال قدرة، جهد، تيار، وتردد المحرك بدقة قبل الـ Autotuning.
FC-01Autotuning1: تعلم ذاتي مع الحبال، 2: تعلم ذاتي بدون حبال (فك الحبال عن الطنبور).
Err 02 / 03 / 04Overcurrent (OC)تيار زائد؛ افحص قصر الكابلات، العزل، ووحدة الـ IGBT.
Err 30Position Anomalyخطأ موقع المصعد؛ افحص الـ Encoder وحساسات التوقف المغناطيسية.
Err 41Safety Circuit Openانقطاع سلسلة الأمان؛ افحص الفولتية على مدخل الأمان ونقاط الطوارئ.
Err 42 / 43Door Lock Faultانقطاع قفل الباب أثناء الحركة أو فشل الإغلاق الميكانيكي.

2. لوحات ARCODE (ARKEL): البرمجة والأعطال الشائعة

الرمز / الإعدادالتوصيف الفنيخطوات المعالجة والصيانة
Shaft Learnتعليم البئر الآلييُنفذ عبر أداة AREM لقراءة مغناطيسات الطوابق وشريط التوقف.
Er01 / PrCPhase Errorعكس أو سقوط أحد الفازات الرئيسية (L1, L2, L3).
Er10Safety Chain (110-140)انقطاع دائرة الأمان؛ راقب شاشة AREM لتحديد النقطة الفاصلة(120, 130, 140).
Er20Door Limit Faultفشل فتح/إغلاق الباب في الوقت المحدد؛ افحص محرك الباب والحساسات.
Er50CANbus Errorخطأ اتصال شبكة CAN؛ افحص الأسلاك (CAN_H, CAN_L) ومقاومة النهاية 120Ω.

🔊 3. دليل تشخيص صفارات وأكواد الـ BIOS (POST Beep & Hex Codes)

الصفارة أو الكود (Hex)العطل المشخّصالإجراء الهندسي السريع
صفارة واحدة قصيرةالنظام سليم (POST Passed)إقلاع طبيعي للوحة الأم.
صفارات طويلة متكررةعطل في الذاكرة العشوائية (RAM Error)نظف بنك الرام أو جرب شريحة أخرى.
صفارة طويلة + 3 قصيرةعطل في البطاقة الرسومية (VGA Error)افحص كرت الشاشة أو مدخل PCIe وتغذية الكرت.
كود 00 أو FF على كرت الفحصالمعالج لا يعمل أو BIOS تالفافحص دائرة تغذية المعالج (VRM) واشحن الـ BIOS.
كود 53 أو C1 أو D4عدم قراءة الرام (Memory Detection)افحص فولتية الرام (1.2V لـ DDR4 أو 1.35V لـ DDR3L).
